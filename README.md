# hyprotechlangs

Welcom to lanuage repository to translate HyProTech!

Original language in folder "en-US".

All langs to translation contains in corresponding folders.

Each folder contain 3 file:
 - items.lang
 - server.lang
 - dictionary.txt
 
Files "items.lang" and "server.lang" is translate file.
 
File "dictionary.txt" used to unification terminology for next translate iteration and filled by translators.
